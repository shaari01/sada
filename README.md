# صدى · محرر الصوت والموسيقى

تطبيق ويب قابل للتثبيت (PWA) لتحرير الأصوات والموسيقى ودمج المسارات، يعمل بلا إنترنت، بواجهة عربية.

- التشغيل محليًا: `npm install` ثم `npm run dev`
- الاختبارات: `npm test` (وحدات + متصفح)
- النشر: تلقائي على GitHub Pages عند الدفع إلى `main` (انظر `.github/workflows/deploy.yml`).

انظر `PROGRESS.md` لسجل المراحل، و`DECISIONS.md` للقرارات.
